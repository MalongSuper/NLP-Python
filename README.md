# Natural Language Processing with Python

This repository stores small projects, experiments, and sample codes related to **Natural Language Processing (NLP)**, mostly implemented in **Jupyter Notebooks**.

The repository primarily focuses on applying **pretrained models and existing NLP libraries** to different language-processing tasks, rather than building every model entirely from scratch.

## Coverage

Topics and projects may include:

* Text preprocessing and tokenization
* Text classification
* Sentiment analysis
* Text similarity and embeddings
* Named Entity Recognition (NER)
* Language modeling
* Text generation
* Transformer-based NLP
* Other NLP tasks and experiments

Some of the codes and topics are inspired by concepts, examples, or exercises from various **popular NLP books and learning resources**. The implementations may be adapted or simplified for educational purposes.

## Notes

This repository is primarily intended for **learning, experimentation, and reference**. The collection may be expanded with additional NLP topics and projects over time.
